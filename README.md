# Summary

Web app project manager that stores data in Notion. The application uses the Notion API to modify pages and data sources and renders them in a custom Web UI.

## Features

- Modular project components. Add or remove modules such as taskboards, diagrams, API specs
- AI collaboration. AI is integrated to assist developers with documentation or general project advice.
- CD/CI integrated tools. Allow users to deploy their projects automatically using third party tools.
